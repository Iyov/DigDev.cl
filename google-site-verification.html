Plantilla de verificacion de Google Search Console

Este archivo generico no valida el dominio por si solo.

Google Search Console exige uno de estos metodos reales:

1. Agregar en index.html el meta tag exacto entregado por Google.

2. Crear un archivo HTML con el nombre exacto del token entregado por Google y con el contenido indicado por Search Console.
